

| Название | Фильтрация списка фильмов и сериалов по эксклюзивности |
| :---- | :---- |
| **Цель** | Предоставить пользователю возможность быстро находить контент, доступный только в сервисе Otium, повысив удобство использования раздела «Библиотека» и увеличив количество пользователей Otium |
| **Требование** | Пользователь должен иметь возможность фильтровать список фильмов и сериалов в разделе «Библиотека» по признаку эксклюзивности. При выборе чек-бокса «Представлены эксклюзивно в Otium» в ответе должны возвращаться только фильмы и сериалы, представленные эксклюзивно в Otium |
| **UseCase** | В разделе «Библиотека» пользователь выбирает чек-бокс «представлены эксклюзивно в Otium». Система отправляет запрос на получение списка контента с параметром фильтрации по эксклюзивности.  Backend обрабатывает запрос, фильтрует фильмы и сериалы по полю `exclusive` и возвращает только контент, доступный эксклюзивно в Otium |
| **Описание изменений** | Необходимо доработать метод `{{FilmsServer}}/films/list {{SeriesServer}}/series/list`  Добавить входной параметр фильтрации `exclusive` типа `boolean`; Добавить поле `exclusive` типа `boolean` в тело ответа для каждого фильма/сериала; Добавить фильтрацию результата по значению поля `exclusive, если в запросе передан параметр exclusive=true` Добавить обработку параметра `exclusive=true` если пользователь выбрал чек-бокс «Представлены эксклюзивно в Otium» — возвращать только фильмы и сериалы с признаком `exclusive=true`. |
| **Контекст** | В ответе запроса {{FilmsServer}}/films/list и {{SeriesServer}}/series/list уже есть элемент «exclusive».  |
