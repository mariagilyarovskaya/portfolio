# RBAC и ABAC

## Роли

| Участник | Признак |
|---|---|
| Клиент | У пользователя есть профиль `Customer` |
| Мастер | `employee.role = BARBER` в конкретном филиале |
| Менеджер | `employee.role = MANAGER` в конкретном филиале |
| Администратор | `employee.role = ADMIN` в конкретном филиале |

## Атрибуты доступа

| Группа | Атрибуты |
|---|---|
| Текущий участник | `userId`, `customerId`, `employeeId`, `employee.role`, `employee.branchId` |
| Запись | `customerId`, `barberId`, `branchId` |
| Мастер, услуга, филиал | `branchId` |

## Правила доступа

| Действие | RBAC: кто может | ABAC: условие доступа |
|---|---|---|
| Смотреть филиалы, услуги и мастеров | Все | Нет ограничения по владельцу ресурса |
| Смотреть свободные слоты мастера | Все | Нет ограничения по владельцу ресурса |
| Создать запись | Клиент | Для текущего пользователя существует профиль клиента |
| Смотреть запись | Клиент | `appointment.customerId = current.customerId` |
| Смотреть назначенные записи | Мастер | `appointment.barberId = current.employeeId` |
| Изменить статус записи | Мастер | `appointment.barberId = current.employeeId` |
| Отменить запись | Клиент | `appointment.customerId = current.customerId` |
| Смотреть записи филиала | Менеджер | `appointment.branchId = current.employee.branchId` |
| Управлять услугами | Менеджер | `service.branchId = current.employee.branchId` |
| Управлять мастерами | Менеджер | `employee.branchId = current.employee.branchId`; управляемый сотрудник имеет роль `BARBER` |
| Управлять филиалами, пользователями и сотрудниками | Администратор | Ограничений по `branchId` нет |
| Логически удалить филиал, услугу или сотрудника | Менеджер, администратор | Менеджер — только ресурс своего филиала; статус ресурса меняется на `DELETED` |

## Общее правило

Пользователь может иметь один профиль `Customer` и несколько профилей `Employee`; для каждой пары `userId` и `branchId` допустим только один профиль сотрудника.
